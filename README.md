# open-fafu-data

**非官方学生项目**：福建农林大学课程资料公开索引（Open FAFU）。本仓库只收录资料的标题、链接、可信度等元数据，**不存放任何课程文件原文**。

## 数据文件

- `data/candidates/candidates_part_*.jsonl`：URL 去重后的 FAFU 专属候选索引（JSON Lines，每行一条；按行数切分，拼接即得完整 1163 条）
- `data/candidates_graded/graded_part_*.jsonl`：同上，附加 A/B/C 证据分级与分类字段

注：因上传接口单次大小限制，数据按约 90KB 切分为多个分片。

字段说明：`title` 标题、`course` 课程、`material_type` 类型（试卷/课件/实验资料/复习资料/公开课等）、`source_site` 来源站、`url` 链接、`credibility` 可信度（高/中/低）、`access` 访问方式（公开/需登录）、`note` 备注、`grade` 证据分级、`category_l1` 一级栏目、`college` 学院、`doctype_xmu` 资料类型（鹭岛书阁口径）。

## 分类体系（参考厦门大学"鹭岛书阁"）

- **一级栏目**：公共课 / 专业课 / 考研 / 工具模板
- **二级**：按学院（生命科学学院、计算机与信息学院、食品科学学院等；"公共基础课"为数理化等分组标签，非正式学院名；"待定"为未识别，待校友校准）
- **资料类型**：真题 / 课件 / 笔记 / 题库 / 课程页 / 其他

当前分布：专业课 969、公共课 177、考研 15、工具模板 2；真题 305、笔记 112、课件 94、题库 34、课程页 538。

## 证据分级

- **A**：页面验真（HTTP 200 + 正文含校名 + 课程名 + 免登公开）
- **B+**：双独立来源链对标题/URL/学校归属一致，且落地页轻探针 200、免登可读
- **C**：候选池（未达 B+ 门槛，不计入核心数）
- **隔离**：疑似未授权教师课件，单独标注，不计入核心数

当前：A=317、B+=701、C=62、隔离=83，核心（A+B+）=1018，覆盖 379 门课程。

口径为"URL 及可见内容严格去重"，不宣称文件级查重。

## 收集方法

公开网络定向搜集（垂直试卷站、文档站、MOOC/课程平台、搜索引擎 site: 反查），多 AI 交叉验证，URL + 标题归一化去重。登录后课程页经学生本人登录后收录（仅记课程名/教师/链接，标"需登录"）；付费内容、网盘密码、教材 PDF、含个人信息的页面不收录。
