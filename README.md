# open-fafu-data

**非官方学生项目**：福建农林大学课程资料公开索引（金山书阁 / Open FAFU）。本仓库只收录资料的标题、链接、可信度等元数据，**不存放任何课程文件原文**。

## 数据文件

- `data/candidates/candidates_part_*.jsonl`：URL 去重后的 FAFU 专属候选索引（JSON Lines，每行一条；按行数切分，拼接即得完整 774 条）
- `data/candidates_graded/graded_part_*.jsonl`：同上，附加 A/B/C 证据分级

注：因上传接口单次大小限制，数据按约 90KB 切分为多个分片。

字段说明：`title` 标题、`course` 课程、`material_type` 类型（试卷/课件/实验资料/复习资料/公开课等）、`source_site` 来源站、`url` 链接、`credibility` 可信度（高/中/低）、`access` 访问方式、`note` 备注、`grade` 证据分级。

## 证据分级

- **A**：页面验真（HTTP 200 + 正文含校名 + 课程名 + 免登公开）
- **B+**：双独立来源链对标题/URL/学校归属一致，且落地页轻探针 200、免登可读
- **C**：候选池（未达 B+ 门槛，不计入核心数）
- **隔离**：疑似未授权教师课件，单独标注，不计入核心数

口径为"URL 及可见内容严格去重"，不宣称文件级查重。

## 收集方法

公开网络定向搜集（垂直试卷站、文档站、MOOC/课程平台、搜索引擎 site: 反查），多 AI 交叉验证，URL + 标题归一化去重。只收录免登录公开页面；付费内容、登录后内容、网盘密码、教材 PDF 不收录。
